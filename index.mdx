# Overview

This platform is a **dynamic, admin-first Flask application** designed with a monolithic architecture and powered by a database-driven interface for maximum flexibility.

The system combines a robust backend with a user-friendly admin panel, allowing all aspects of the application—content, configuration, and UI text—to be managed directly from the browser.

## Key Highlights

- **Monolithic + Application Factory Architecture**  

  A single, unified codebase using Flask’s factory pattern to promote modularity and testability.

- **Admin-First Philosophy**  

  Every content and configuration change can be made by administrators without touching the codebase.

- **Database-Driven UI & Translations**  

  All UI strings, labels, and supported languages are stored in the database, ensuring real-time updates.

- **Scalable Data Layer**  

  PostgreSQL powers the production database, with SQLAlchemy ORM for model abstraction and Flask-Migrate for schema versioning.

- **Performance Optimized**  

  Frequently used UI translations are cached in memory to reduce database load and improve render times.
